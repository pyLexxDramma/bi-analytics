### № 1 — Release: сайдбар без «Данные», только версия

**Запрос:**  
На release не показывать блок «Данные» (Загрузить вручную / Из папки web/ / FTP → web/). Данные из web/ подгружать автоматически после авторизации. В сайдбаре оставить только выбор подгруженной версии данных.

**Сделано:**

- `auth.py`: на release — селектор версии внизу сайдбара; dev/admin — полная панель без изменений.  
- `project_visualization_app.py`: `apply_web_version_pick()` на release без admin-панели; автозагрузка web/ при входе (существующая логика `_pending_web_folder_load` / `_release_web_autoload_tried`).

**Сверка с `web/`:**  
- режим release: `BI_ANALYTICS_RELEASE_MODE=1` или ветка `release`; источник — только `web/`, без `new_csv/`.

**Скрины (запрошены / получены):**  
- до правки: сайдбар с блоком «Данные» (localhost, dev-режим); после — проверка в release-режиме.
