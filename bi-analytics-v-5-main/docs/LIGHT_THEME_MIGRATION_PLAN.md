## Цикл на одну вкладку

1. **Пользователь:** вкладка + скрины/описание багов.
2. **Агент:** фикс в коде.
3. **Пользователь:** проверка (фильтры, чекбоксы, переключение тем/вкладок).
4. **Пользователь:** «ок» → commit/push в `main`, при необходимости в `release`.
5. Следующая вкладка по порядку §12.

Push в `main` / `release` — только после явного OK пользователя по текущей вкладке.
