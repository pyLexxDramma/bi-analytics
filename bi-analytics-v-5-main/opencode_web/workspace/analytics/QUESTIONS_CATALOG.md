# Каталог типовых вопросов → скрипты → формат ответа

Источник вопросов: `questions.md` в корне репозитория.  
Перед ответом: `cat /workspace/AI_DATA_RULES.md` и этот файл; выполни **один или несколько** скриптов по смыслу вопроса.

**Формат ответа пользователю (обязательно):**
1. Краткий вывод (1–2 предложения) с главной цифрой или фактом.
2. Детализация: список или **markdown-таблица** (до 15 строк) из CSV — колонки как в файле, без выдуманных строк.
3. Если в `AI_DATA_RULES.md` для вопроса «Нет» — честно: «По текущим данным в БД ответить нельзя» + чего не хватает.
4. Без приветствия, без «сейчас запущу скрипт», без вставки содержимого файлов/cat/XML.
5. **Графики** — пока не требуются (не добавлять строки с PNG, если пользователь не просил диаграмму).
